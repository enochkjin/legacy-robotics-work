# Life-Detection Payload
My work on a spectrophotometer and NPK sensor based payload system during my time on Legacy Robotics at UCI.

Legacy Robotics at UCI is dedicated to making UCI's first mars rover in preparation for the annual University Rover Challenge (URC). My work centered around a mandatory life detection payload, specifically designing and wiring the two life detection capabilities. These are an NPK sensor and a custom-built spectrophotometer.
